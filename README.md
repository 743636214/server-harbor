# Server Harbor · 团队服务器工作空间

React + Node.js / Express + MySQL。团队共同管理服务器，支持独立账号、权限控制、网页 SSH、Termius、Linux 实时监控、多云安全组、管理审计与加密会话录制。

当前保存在 `~/codes/server-harbor`，暂不部署公网。

新环境安装、各系统步骤、密钥配置、HTTPS、迁移和排错见 **[新环境部署指南](DEPLOYMENT.md)**。其中已明确区分可直接执行的 macOS 初始化流程与 Linux / Windows / Docker 尚需准备的秘密管理器适配。

## 本地使用

```sh
cd ~/codes/server-harbor
npm start
```

打开 <http://127.0.0.1:4317>。首次进入创建管理员；如果此前已经设置过单人版管理密码，升级后账号为 `admin`，原密码继续有效，原服务器和加密凭据保留。

```sh
npm run dev    # 开发：前端 5173，后端 4317
npm run build  # 生成界面构建
```

## 账号与权限

所有成员共享同一服务器库，每个人有独立的收藏和登录会话。管理员拥有全部权限，并维护成员、云 API 密钥。

普通成员按账号单独授权：

| 权限                  | 允许的操作                                 |
| --------------------- | ------------------------------------------ |
| 新增服务器            | 添加服务器和加密 SSH 凭据                  |
| 修改服务器 / 信任指纹 | 修改配置与凭据、确认或更换主机指纹         |
| 删除服务器            | 删除服务器记录；保留审计和录制             |
| SSH 连接与监控        | 网页 SSH、Termius、读取 Linux 指标         |
| 安全组管理            | 关联云安全组、读取规则、新增和删除端口放行 |

未授权的请求会在后端返回 403，并记入审计。普通成员默认可以查看和连接，新增、修改、删除、安全组操作默认不授权。调整权限、停用账号或重置密码会撤销该账号已有登录与 SSH 会话；至少保留一名可用管理员。

登录防暴力破解：同一账号在北京时间当天连续输错 5 次后，暂停登录至次日 00:00；锁定期间即使密码正确也不能登录。登录成功清零失败次数，跨日自动重新计数。计数与解封时间存入 MySQL，换 IP、改账号大小写、更名、重启或多实例都不能绕过。第 5 次失败会撤销该账号已有登录及 SSH 连接，锁定与首次到期解锁均记入操作日志。管理员手动停用的账号不会被自动启用。

前 4 次失败会显示剩余次数，第 5 次起显示准确的北京时间解封日期；成员列表显示登录锁定状态。管理员可在“成员与权限”中点击锁定账号旁的“解除登录锁定”，立即清零失败次数并允许重新登录，操作记录管理员、目标账号及原锁定信息。解锁不会恢复旧 Cookie / SSH 会话，也不会自动启用管理员手动停用的账号。IP 请求频率限制仍保留，作为账号锁定之外的保护。

## 网页 SSH 与 Termius

- **网页 SSH**：点击服务器行的“网页 SSH”，直接在浏览器中交互操作，支持粘贴、调整终端尺寸和断开 / 重连。点击弹窗外部不会关闭或断开，Esc 继续交给远程终端；通过右上角关闭或“断开”结束会话。
- **Termius**：点击 Termius，由浏览器启动使用者自己电脑上的客户端。服务器端不再调用 macOS 的 `open`。
- **首次连接**：管理员或具有修改权限的成员核对主机指纹。指纹改变会阻止连接，需要重新核实。

```text
浏览器网页终端 → 登录鉴权的 WebSocket → 同一 SSH 网关 → 远程 SSH
本机 Termius   → 公网 / 本地 SSH 网关                   → 远程 SSH
```

Node.js 从 MySQL 解密已保存的凭据，验证主机密钥后登录远程服务器。网关接入使用绑定账号、90 秒过期、只能使用一次的随机票据；使用票据时再次检查账号和连接权限。

Termius 显示原服务器名称与真实账号，连接地址为网关地址，临时用户名包含票据。真实 SSH 密码 / 私钥不会放入 Termius 链接或剪贴板。每个账号最多同时准备或保持 5 个 SSH 连接。

当前网关只提供交互终端，不提供 SFTP、端口转发或 SSH Agent 转发。只通过本系统建立的会话会被录制；绕过系统直接连接服务器的操作不在本系统审计范围。

## CPU、内存、磁盘监控

点击服务器名称或“服务器监控”图标：

- 每 5 秒读取 CPU 使用率、CPU 核数、负载、内存和 Swap、运行时长。
- 展示各磁盘分区的容量、已用、可用和使用率。
- 保留当前窗口最近 60 次采样趋势，支持暂停刷新。
- 首版支持 Linux，通过固定的只读命令读取 `/proc` 和 `df`，无需安装代理。

监控使用该服务器的 SSH 凭据，需要 SSH 连接权限，并遵循主机指纹校验。CPU 使用率按两次采样差值计算，内存按 `MemAvailable` 计算。监控读取会记录账号、服务器和采样操作。

## 多云 API 密钥与安全组

已实现四类官方 SDK 适配器：腾讯云 VPC、阿里云 ECS、华为云 VPC、AWS EC2。其他厂商可按 `server/cloud/adapters.mjs` 接口继续扩展。

使用步骤：

1. 管理员在“云账号与密钥”添加账号名称、云厂商、AccessKey ID / SecretId、Secret / SecretKey，以及默认区域。临时凭据可以填写 Token；华为云还需要对应区域的项目 ID。
2. 打开某台服务器的“安全组 / 开放端口”，选择云账号和区域，读取云端安全组列表或填写已知安全组 ID。
3. 确认这个安全组确实关联目标实例，再保存管理关联。
4. 查看已有入站 / 出站规则，按需新增 TCP / UDP 单端口或连续端口范围，明确填写来源 / 目标 IPv4 或 IPv6 CIDR。
5. 删除规则前显示完整目标，并检查规则令牌、当前规则内容及腾讯云规则版本，避免使用过期索引误删。

维护密钥支持新增、替换、停用和删除；已有服务器关联时不能删除账号。Secret 不会回传浏览器，编辑留空保留原值。加密主密钥保存在 macOS 系统钥匙串（Linux 使用外部秘密管理器），云密钥与 SSH 凭据使用不同的认证上下文。

安全组规则影响所有关联该安全组的实例。保存管理关联不会替实例更换实际安全组，也不会修改 Linux 防火墙。API 密钥需在对应云平台具备查询、添加和删除安全组规则的权限；建议使用范围仅限目标资源的子账号凭据。当前未提供真实云 API 凭据，尚未进行云端联调，也未修改任何真实云规则。

## 操作日志与 SSH 录制

“操作日志”包含账号、服务器名称及 ID、时间、动作、结果、来源 IP 和不含凭据的变更详情：

- 账号登录 / 退出、成员创建、权限调整、密码重置、权限拦截。
- 服务器新增、修改、删除、个人收藏、主机指纹检查和信任。
- 网页 SSH / Termius 连接请求、接入、断开、失败与重启中断。
- 监控读取、云密钥维护、云安全组读取 / 关联和规则新增 / 删除。
- 管理员查看 SSH 录制。

管理员查看全员日志，普通成员只查看自己的日志。日志支持账号 / 服务器 / 动作搜索、结果和日期筛选、分页。删除服务器不会删除其历史名称和记录；管理界面不提供删除日志的入口。

SSH 会话输入按键与输出按块加密写入 `.data/recordings/`，仅管理员可在“连接记录”中回放。支持播放、暂停、速度、完整输出和原始输入按键查看。录制具备块认证、序号和结束校验值，检测到篡改后停止回放。

输入录制可能包含隐藏输入的密码或业务内容，请仅让可信管理员查看。终端按键 / 屏幕录制无法可靠还原编辑器操作、控制字符等为独立系统命令；如需逐条进程级命令审计，还需要在目标 Linux 配置 auditd / tlog 等远端设施。

默认单次录制容量 32 MB，达到上限或录制写入失败时结束连接，避免继续产生未录制的会话。当前无自动清理策略，应按容量规划备份与保留周期。具有数据库和主密钥访问权限的人仍可修改底层记录；严格不可变审计需另接外部存储。

## 加密、备份与升级

- SSH / 云凭据、会话录制：AES-256-GCM；密码：随机盐与 scrypt。
- 登录会话存入 MySQL，Cookie 为 HttpOnly / SameSite=Strict；公网模式使用 Secure Cookie。默认 8 小时过期。
- 数据库密码、主密钥在 macOS 系统钥匙串，`.env` 只保存引用和非秘密配置；禁止向配置文件写入密码。
- 网关主机私钥加密保存在 `.data/bridge-host-key.enc`，权限 `0600`；本地数据库使用 Unix socket。
- 本地模式强制只监听回环地址，不能用 `HOST=0.0.0.0` 暴露 HTTP。公网模式强制 HTTPS。
- 升级采用新增表，保留旧管理员密码、原服务器、凭据和历史记录，无需修改现有表结构。

```sh
npm run backup
```

该命令需要本机 `mysqldump`，SQL 通过管道直接 AES-256-GCM 加密写入 `.sql.enc`，不产生明文 SQL 中间文件。完整恢复还需要系统钥匙串 / 秘密管理器中的原 `VAULT_KEY`、网关加密主机密钥和录制目录。丢失 `VAULT_KEY` 无法恢复凭据或录制。

旧配置迁移：`npm run secrets:migrate`。迁移在钥匙串写入并验证成功后替换 `.env`，保留原主密钥和网关指纹，并把旧 SQL 备份加密；不会生成含秘密的配置备份。

首次在另一台本机配置数据库：`npm ci && npm run setup`。初始化脚本只使用 MySQL root 密码创建独立数据库与专用运行账号，不在项目中保存 root 密码。

## 未来公网部署

已提供 Dockerfile、`deploy/compose.yaml` 和 Caddy HTTPS 配置；目前只保留部署材料，不对外发布。

完整步骤见 [部署指南第 9 章：Docker](DEPLOYMENT.md#s9)。先完成秘密管理器适配器、两个镜像内依赖与身份、MySQL 秘密服务可达性、共享 socket 权限和 HTTPS 配置，再执行构建 / 启动；不能只生成 `.env.production` 就直接部署。

`npm run prepare:deploy -- ops.example.com` 是 macOS 部署材料准备命令，不是 Linux 初始化器或秘密同步工具。已有项目主密钥时会沿用原值；完全独立的新环境应使用独立的秘密空间与主密钥。

生成脚本只在 `.env.production` 写入域名、端口等公开配置，部署密码与原 `VAULT_KEY` 保存在本机钥匙串。迁移到 Linux 前必须通过安全渠道将这些秘密放入外部秘密管理器，并提供 `deploy/secrets-provider/read-secret` 可执行适配器。适配器接收一个名称参数（`MYSQL_ROOT_PASSWORD` / `MYSQL_APP_PASSWORD` / `VAULT_KEY` / `BOOTSTRAP_TOKEN`），从秘密管理器通过已验证的 TLS 和工作负载身份读取对应值，只输出到标准输出，不写文件或日志；不能在适配器源码里硬编码秘密。

Compose 不再通过环境字段持久化密码。MySQL 启动时从适配器读取到进程内存，应用通过相同适配器读取。未提供适配器时启动失败，避免退回明文配置。适配器和其依赖必须在两个容器中可执行。此适配器尚未与具体厂商秘密管理器联调，不能直接将当前模板视为已验收的公网部署。

数据库在容器中关闭 TCP，只使用共享 Unix socket。HTTP 只在容器网络交给固定 IP 的 Caddy，可信代理仅限该 IP；外部开放 80 / 443 与 SSH 网关 2222。WebSocket 使用同一 HTTPS 域名。若网络地址段冲突，需同步修改 Compose 子网、Caddy IP 和可信代理 IP。远程 MySQL 连接必须启用 `MYSQL_TLS=true` 和证书 / 主机身份校验。

当前为单个 Node.js 网关实例；SSH 活动会话保存在该实例内存中，重启会断开会话，但账号、凭据、审计和录制持久化。此配置未在 Docker 环境或公网进行部署验证。

## 开发与当前验证范围

```sh
npm test
npm run test:integration
```

集成测试和安全测试只访问 `server_harbor_test`，使用模拟 SSH / HTTPS 服务；不会登录真实服务器或调用真实云 API。安全测试覆盖并发猜密码、伪造 Cookie、来源与 Host 检查、成员越权、WebSocket 鉴权、退出后重放、SSH 指纹替换、HTTPS 伪造证书 / 域名以及流量中密码与 Cookie 的可见性。执行：

```sh
npm run test:security
npm run test:lockout
node scripts/security-scan.mjs
```

安全检查结论与边界见 [SECURITY-REVIEW.md](SECURITY-REVIEW.md)。登录、初始化、成员设置 / 重置密码和修改密码均支持“显示 / 隐藏”，默认隐藏，移开焦点后恢复隐藏。退出入口位于页面右上角和侧栏；退出会撤销服务端登录、待用票据及该账号 SSH 会话。

源码：`src/` 界面；`server/app.mjs` 鉴权与 API；`server/ssh.mjs` 网关；`server/web-terminal.mjs` 网页 SSH；`server/monitor.mjs` 只读监控；`server/cloud/` 多云适配与 API；`server/recordings.mjs` 加密录制。
